# Security Policy

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The APEX14 team takes framework security seriously. If you discover a vulnerability or potential security risk in APEX14:

1. **Do not create a public issue** on GitHub.
2. Email full reproduction steps and advisory details to security@apex14.dev (or open a private GitHub Security Advisory).
3. Include:
   - Affected version(s)
   - Proof of Concept (PoC) code
   - Severity and potential impact analysis
4. You will receive an acknowledgment within 48 hours.
5. We will coordinate a patched release and appropriate disclosure window.
